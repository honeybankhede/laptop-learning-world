# 💻 Laptop Learning World

> **Don't just learn computers. Live the experience.**

Laptop Learning World is a browser-based 3D virtual computer academy. You control a human character inside an office, do real hands-on tasks (plug in cables, build a PC, use a simulated desktop), and learn computers day by day. Hindi + English.

**Play online:** https://honeybankhede.github.io/laptop-learning-world/

## Features
- Cinematic intro (laptop opens, camera flies into the screen) with a skip button
- 3D office: walk, run, sit/stand, look around, interact with objects
- Real tasks with live validation, hints, mistake explanations and retries
- XP, levels, badges, motivational quotes and a 22-day roadmap
- Hindi and English, desktop and mobile controls, quality settings (Low / Medium / High)

## Curriculum
| Days | Topics | Status |
|---|---|---|
| 1-2 | Start a computer, cables, boot, PC parts and slots | Playable |
| 3-4 | Ports, hardware vs software, boot process, restart/sleep/shut down | Playable |
| 5-7 | Windows desktop, files and folders, settings, installing, updates | Playable |
| 8-10 | Internet, search, email, online safety, Wi-Fi and IP | Playable |
| 11-22 | Office tools, cloud, VS Code, HTML/CSS, JavaScript/Python, Git/GitHub, databases, cybersecurity, BIOS, backups, deployment, AI tools | Coming next |

## Controls
| Action | Desktop | Mobile |
|---|---|---|
| Move | W A S D / arrows | Joystick |
| Run | Shift | Run button |
| Look | Drag mouse | Drag screen |
| Interact | E | E button |
| Sit / stand | F | F button |
| Hint | H | H button |
| Auto-walk to next task | N or the blue button | Blue button |
| Pause | Esc | Pause button |

## Run locally
1. index.html`
2. Double-click it (internet is needed for the Three.js and GSAP CDN scripts)

## Tech
Single-file HTML, [Three.js](https://threejs.org/) r128, [GSAP](https://gsap.com/) 3.12.5. No backend: progress is saved in your browser (localStorage).

## Privacy and safety
The simulated desktop, email and password lessons never ask for real passwords or personal data.
